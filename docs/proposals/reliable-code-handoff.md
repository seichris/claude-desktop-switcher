## 背景とゴール

手動終了後、最後に起動を確認した参加環境の完全なローカルCodeストアを次の環境に引き継ぐ。生バイトの差だけで複数の変更と判定すると、フォーカスやGC時刻の更新で通常の起動が停止する。ユーザーは実装、検証、セキュリティレビュー、PR、CI確認後のマージとローカル導入を承認済み。

## 設計原則と仕様

- 起動要求やactiveの選択だけでは権威を移さない。対象の単一プロセスを確認し、世代と環境の保存先を結び付けた起動記録を原子的に保存してから予約を解除する。mtimeとlastFocusedAtを権威の選択に使わない。
- 同期から起動確認まで同じロックを保持する。未確認の起動、中断、不明なプロセス状態は停止する。確定記録の保存直後に中断した場合だけ、対応する予約を安全に清掃できる。
- 確認済み環境の完全なストアを採用する。削除、tombstone、サイドバー、未知のフィールド、リポジトリ、worktree、プリセットを保持する。
- JSONの整形差、セッションファイル直下の数値lastFocusedAt、git-worktrees.jsonのuntrackedDirGc.cwds内の数値時刻だけを非内容変更とする。既存レコードの時刻の最大値だけを合流し、削除されたセッションやGC項目を復活させない。未知の構造は内容変更として扱う。
- 未使用の参加環境は保存した基準と比較する。既知の古い完全ストアは置き換え可能。直近16世代より古い状態や未知の独立した内容変更は、外部更新として明示的に競合停止する。
- 旧設定には確認済み起動の証拠がない。生データの指紋の変更が1環境以下なら直接移行する。複数なら保存済みバックアップで基準を検証し、内容変更が1環境以下なら移行する。複数なら元環境を明示して再設定する。過去のactiveや最終起動の表示時刻を根拠にしない。
- バックアップ後、停止状態、環境ID、元データを再検証してからjournalを保存する。回復時も未知の更新を上書きしない。
- 認証、Keychain、Cookie、ブラウザストレージ、プロセス環境やメモリは読まない。ネットワーク、追加ログイン、自動終了、Accessibility検査を追加しない。実データをテストに使わない。

## リスクと対応

同一ユーザーの悪意あるファイル置き換えを完全に防ぐOS境界ではない。リンク・特殊ファイル・過大入力・深すぎる木を拒否し、書き込み直前の再検証と回復可能なバックアップで保守的に停止する。起動観測前のクラッシュは推測せず、終了後の明示的な解除と元環境の選択が必要。

## スコープ外

Claudeの実切替、実Codeデータの移行、クラウドChatやProjectsの共有、自動終了、認証処理、利用量の取得。

## 検証結果

ローカルのworkspace build、clippy、fmt、Rustの223テストと日本語検査の22テストが成功した。日英のdevモックでエラーとReopenの表示を検証し、実Claudeのデータは使用していない。独立したセキュリティ・仕様レビューの指摘を修正し、再レビューで未対応の実質的な指摘は残っていない。旧journalの互換性、段階保存後の再検証、アカウント変換後のサイズ制限、確定記録の保存失敗、既知の状態の再訪も合成テストで検証した。実Claudeの切替は実施せず、導入後の実利用の検証とは区別する。

PR #9の最終headでBuild、Test、Lint、Deny、Security、スクリーンショットの6チェックが成功し、2026-10-19に787032ea434ed756269dfe3832f0970d6e733b09へマージした。macOSランナーで日英16枚のスクリーンショットを再生成し、競合とReopenのエラー分類もdevモックで検証した。マージしたコードとローカルビルドのソース一致、ad-hoc署名、インストールしたアプリとCLIの版とバイナリ一致を確認した。直前のアプリとCLIをバックアップし、Claudeのプロセスを維持したままSwitcherだけを再起動して導入した。実Codeストアの同期や実際の環境の起動は行っていない。最初の実利用時の引き継ぎは、作業と入力待ちを終えて手動終了する通常の経路で検証する。
