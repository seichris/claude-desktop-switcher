## 背景と合意済みの範囲

同じ利用者の複数環境で、既存のClaudeを起点にローカルCodeの全レコードを引き継ぐ。対象はDesktopのローカルCodeサイドバー、ワークツリー管理、Codeの保存済み設定。既存の共有された会話履歴・メモリ・入力履歴をそのまま利用する。認証情報を抽出せず、Desktopのサインインを維持し、Claude Code CLIへのサインインを追加しない。

## 設計

- 任意の環境名を受け付ける管理者向けCLIで明示的に有効化する。実アカウント、メールアドレス、環境数をコードに固定しない。
- 全Claude Desktopの終了を確認し、既存の起動経路で切り替える直前に完全なローカルCodeストアを同期する。起動中のストアやClaude本体を変更しない。
- サイドバーJSONのフィールドを選別しない。削除マーカー、アーカイブ索引、ワークツリー所有・回収状態を含めて引き継ぐ。環境ごとのアカウント・組織ディレクトリは維持し、Codeプリセットのアカウントキーだけを対応付ける。
- 初回は指定された元環境が正。以後は前回同期時の指紋から変更された1環境が正。CSW外から起動した環境の変更も検出する。変更がなければ同期せず、複数環境が独立して変更された場合は拒否する。
- 対象はローカルCodeの固定パスだけ。Cookie、Keychain、config.json、ブラウザストレージ、Chat/Cowork、利用量キャッシュには触らない。
- 書き換える前に全対象を非公開のバックアップへ保存する。中断後は非公開の処理記録と選んだ元データのバックアップから予定していたコピーを完了し、上書き前のデータも維持する。リンク、ハードリンク、特殊ファイル、過大な入力、複数のアカウント・組織の曖昧な対応は拒否する。
- 同期と起動を同じロックで直列化し、起動を観測するまで非公開の予約を保持する。起動を確認できなければ、全Claude終了後の`csw unshare-code`と元環境を明示した再設定で解除する。
- 同じ利用者が1環境ずつ使うための機能。クラウドProjects/Chat、独立したウィンドウ間の同時編集、Web側のカスタムグループ設定は対象外。

## 規模と変更先

利用者は既存のDesktop環境を使う上級者。設定用CLIと既存の起動処理への同期を追加し、別の常駐サービスやClaude本体のパッチは導入しない。起動後の操作は従来どおり。

- core：共有グループ、完全コピー、バックアップ、停止ガード、切替時の同期。
- CLI：明示的な有効化コマンドと、同期を無効にする`csw unshare-code`。無効化しても現在のローカルデータ・ログイン・バックアップを維持する。参加環境は無効化後に削除できる。
- docs：日英ガイド、仕様、プライバシー説明。

## 検証と完了条件

- 元環境からの上書き、逆方向の更新、削除マーカー、未知のJSONフィールドの保存をテストする。
- 認証用のダミーファイルがバイト単位で不変であることを確認する。
- 起動中、曖昧な保存先、リンク、ハードリンク、壊れた設定で変更を拒否する。
- fmt、clippy、build、tests、独立レビュー、GitHub CIを確認する。
- 実環境のバックアップ後に適用し、Desktopの保存済みログインとローカルCode一覧を確認する。追加のCLIログインは行わない。
